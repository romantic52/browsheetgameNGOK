# 7 дней в НГОК

Неофициальная браузерная визуальная новелла о семи странных днях в колледже. Вдохновлена жанром атмосферных визуальных новелл, но содержит оригинальный сюжет, персонажей и графику.

## Запуск

Откройте `index.html` в современном браузере — **не требуются ни установка, ни сервер, ни сборка**. Либо опубликуйте репозиторий через GitHub Pages: **Settings → Pages → Deploy from a branch → main → /(root) → Save**. После публикации игра будет доступна на `https://romantic52.github.io/browsheetgameNGOK/`.

## Что есть в MVP

- семь сюжетных дней с развилками;
- четыре персонажа: Лера, Миша, Даша, Артём;
- несколько вариантов финала, зависящих от решений;
- семь оригинальных SVG-фонов и схематичные персонажи;
- автоматическое сохранение в `localStorage`, ручное сохранение, продолжение игры;
- история диалогов, управление с клавиатуры, адаптивная верстка;
- необязательный фоновый звук через Web Audio API.

## Управление

- **Клик**, **Пробел** или **Enter** — следующая реплика.
- **1**, **2**, **3** — выбрать вариант ответа.
- **Esc** — закрыть окно истории/описания.

## Структура

- `index.html` — интерфейс, фоновые иллюстрации и элементы игры.
- `styles.css` — оформление и мобильная адаптация.
- `game.js` — история, развилки, сохранение и концовки.

Сюжетные эпизоды описаны объектом `story` в `game.js`. Для новой ветки достаточно добавить узлы с полями `day`, `scene`, `who`, `text`, `next` или `choices`. Игровые события не требуют специального движка.

## Текущие ограничения

Это **первый игровой прототип**, а не законченная новелла: дни пока короткие, портреты схематичные, используется простой синтезированный фон вместо полноценного саундтрека. В дальнейшем можно расширить главы, добавить настоящие спрайты, CG-арты, музыку и дополнительные маршруты.

## Дисклеймер

Все персонажи и события вымышлены. Это неофициальный фанатский проект, не связанный с администрацией НГОК и создателями других визуальных новелл.
